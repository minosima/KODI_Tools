# KODI_Tools
KODIを音楽サーバーとして使用しています。
スマートプレイリストに任意の画像が設定できる方法を見つけたので、
簡単に専用画像を作成するツールとスマートプレイリストを作成するツール（日本人アーティストの表記揺れ対応）を作りました。
作成までの試行錯誤、手順は下記にメモしています。
https://ncos1.hatenablog.com/



＊　日本人アーティストの表記揺れ対応の例
姓・名
松任谷　由美
matusutouya yumi
を入力すれば、表記揺れをカバーできるはず。
